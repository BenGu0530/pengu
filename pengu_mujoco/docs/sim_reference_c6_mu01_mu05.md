## Velocity — per-footfall method

Body position sampled at every footfall, consecutive samples differenced. Turning counts;
within-stride oscillation cancels because every touchdown is the same gait phase.
Footfalls detected from foot-body height. `v_pooled` = total distance / total time;
`v_mean` = mean of per-step velocities; `v_net` = ||end - start|| / time for comparison.

## Attitude and actuator load

A = hip-axis (lower body) roll, T = torso roll, both as tilt about the torso hinge axis;
J = torso joint angle, T = A + J. The controller targets T = kappa * A, so T/A is its
objective. Torques are p95 over the window; stall is 4.1 N.m.

## Contact and actuator model as configured

```
option        timestep 0.001   integrator implicitfast
              friction cone PYRAMIDAL (default)   impratio 1 (default)
floor         type plane   condim 3 (default)   geom_priority raised above the feet
              friction[0] set per surface; solref/solimp at defaults
foot geoms    friction 0.9 0.005 0.0001
joints        frictionloss 0.1   armature 0.005
actuators     position servo, kp 50, dampratio 1, forcerange +-4.1 N.m
              torso ctrlrange +-0.7854 rad;  NO velocity limit on any actuator
torso PID     kappa 2, kp 2.0, ki 0.1, kd 0, clamp +-45 deg, stepped at 1 kHz
```

Only `friction[0]` (sliding) is changed per surface. **Torsional friction stays at 0.005
and rolling at 0.0001 for every mu**, i.e. the ice and the lab floor are given identical
resistance to a foot pivoting.
